# Class for Simulation Results

A class for simulation results.

## Details

`SimulationResults` is the basic class for

- [`SimulationResultsMeans`](https://docs.rpact.org/qtd/reference/SimulationResultsMeans.md),

- [`SimulationResultsRates`](https://docs.rpact.org/qtd/reference/SimulationResultsRates.md),

- [`SimulationResultsSurvival`](https://docs.rpact.org/qtd/reference/SimulationResultsSurvival.md),

- [`SimulationResultsCountData`](https://docs.rpact.org/qtd/reference/SimulationResultsCountData.md),

- [`SimulationResultsMultiArmMeans`](https://docs.rpact.org/qtd/reference/SimulationResultsMultiArmMeans.md),

- [`SimulationResultsMultiArmRates`](https://docs.rpact.org/qtd/reference/SimulationResultsMultiArmRates.md),

- [`SimulationResultsMultiArmSurvival`](https://docs.rpact.org/qtd/reference/SimulationResultsMultiArmSurvival.md),

- [`SimulationResultsEnrichmentMeans`](https://docs.rpact.org/qtd/reference/SimulationResultsEnrichmentMeans.md),

- [`SimulationResultsEnrichmentRates`](https://docs.rpact.org/qtd/reference/SimulationResultsEnrichmentRates.md),
  and

- [`SimulationResultsEnrichmentSurvival`](https://docs.rpact.org/qtd/reference/SimulationResultsEnrichmentSurvival.md).

## Fields

- `seed`:

  The seed used for random number generation. Is a single numeric value.

- `iterations`:

  The number of iterations used for simulations. Is a single numeric
  value representing a whole number.
