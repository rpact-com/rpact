# Render Quantitative Operating Characteristics

Renders the parameters and a preview of the probability table.

## Usage

``` r
.showQtdOperatingCharacteristics(
  object,
  showType,
  digits,
  consoleOutputEnabled,
  maxRows
)
```

## Arguments

- object:

  An OperatingCharacteristics object.

- showType:

  Output mode.

- digits:

  Display precision.

- consoleOutputEnabled:

  Whether to print or collect the output.

- maxRows:

  Maximum number of probability rows to show.

## Value

Invisibly, whether the output mode was handled.
