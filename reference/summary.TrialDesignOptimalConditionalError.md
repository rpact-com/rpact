# Summary of the optimal conditional error trial design

Provide an overview of the operating characteristics of the optimal
conditional error trial design.

## Usage

``` r
# S3 method for class 'TrialDesignOptimalConditionalError'
summary(object, ...)
```

## Arguments

- object:

  Design object of class `TrialDesignOptimalConditionalError`

- ...:

  Additional arguments for the generic method.

## Value

The design, invisibly, after printing its operating characteristics.
